# OMÉGA-R v0.14 — retour d'expérience E553 (21 novembre 2026)

**Nature :** erreur de conception du protocole de laboratoire, et non preuve de faiblesse de la compression `cmix-neif-2.0`.

## Sources observées

- Échec à la [compilation du premier essai, run 44948098491](https://github.com/Chinoir29/hutter-omega-r/actions/runs/44948098491) : ajout du chemin `-c` pour `AUX_BUILD=0` sans rendre accessible `provide_dict_file()`. Correction du code de laboratoire publiée, avec tests de garde-fous.
- [Second essai GitHub 44948332114](https://github.com/Chinoir29/hutter-omega-r/actions/runs/44948332114) : source upstream épinglée, patch contrôlé, compilation réussie, authentification SHA256 du milliard d'octets réussie, projection de **65 536 octets** dans le vocabulaire gelé de 208 valeurs : réussie. Le jeu de laboratoire provient d'une **projection irréversible** de `enwik9` et n'est pas le corpus du Hutter Prize.
- Lancement de `cmix -c input coder.bin` dans le mode compilé de laboratoire : **échec immédiat (code 255), E553, E256**. Le journal indique un RSS d'environ 8 128 Kio et une durée affichée de 0,00 s : l'échec précède toute compression significative.
- [Artefact de diagnostics v0.14](https://github.com/Chinoir29/hutter-omega-r/actions/runs/44948332114/artifacts/14724179831).

## Localisation de la cause

Dans la révision du concurrent `35d1957a5074db802fc134126afc77b76d931761`, fonction `RunCompression()` de `src/runner.cpp`, se trouve :
```cpp
if (!MetablockInert() && !rule_stages::DateiEnc(temp_path)) {
    msg_note(553);
    return false;
}
```

`ERRORS.md` associe le même code `E553` à plusieurs erreurs, dont « rule stages: encoding failed ». Ici, la combinaison du code source et du traitement d'un flux brut appuie ce diagnostic, mais le log ne contient pas de trace native distinguant à elle seule ces sous-causes. Il est donc formulé comme cause **probable** à confirmer expérimentalement, pas comme preuve mathématique.

La version finale du concurrent attend des règles textuelles et des métadonnées spécifiques à son flux de prétraitement et à son dictionnaire embarqué. Une projection de 65 536 octets dans son alphabet gelé **ne satisfait pas automatiquement ses contraintes sémantiques**, même lorsque chaque byte est autorisé.

## Correction limitée v0.14.2

La prochaine tentative expérimentale épingle toujours la même révision et le même blob `src/runner.cpp`, conserve le Transformer et SEMCACHE, mais neutralise **seulement pour les commandes de laboratoire `-c` / `-d`** les trois fonctions de métadonnées (metablock, author block, timestamp). Un patch de source dont les emplacements ne correspondent pas exactement à la révision amont est refusé.

La réussite ne sera revendiquée qu'en présence d'une reconstruction SHA-256 exacte du jeu **modifié avec perte**. Aucune conclusion ne sera tirée pour le score sur `enwik9` intégral, l'autonomie du décompresseur de concours ou les contraintes CPU/RAM du jury.

**Statut :** problème diagnostiqué, correction construite. Aucune récompense, soumission ou score officiel.
